### 🧬 About

Full-stack engineer at **[@GenoGra](https://github.com/GenoGra)**, where I help design and build
the software platform behind GPU-accelerated **pangenome graph** analysis — from the
distributed job engine to the interfaces researchers actually use.

M.Sc. in Computer Science & Engineering (AI track) @ **Politecnico di Milano**.
Thesis in Computer Vision: *Vessels Detection and Tonnage Regression for Marine Surveillance*.

I like the unglamorous part of AI and HPC: making advanced methods reliable,
observable, and boring enough to run in production.
